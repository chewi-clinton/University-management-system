This repository contains Module 3 of a modular ERP System, developed as part of a Software Engineering academic project, focusing on Administration & Human Resource Management, Library Management, Role-Based Access Control (RBAC), a Unified Student Dashboard, Asset and Bus Tracking, and Automatic Notifications. The system is implemented using HTML, CSS, JavaScript, and JSON, following a modular and scalable design that allows easy integration with other ERP modules such as Academic and Finance. It fulfills key functional requirements including staff profile management, attendance and leave tracking, library book issuance and fines, granular user roles (Admin, Student, Bus Coordinator), student self-service dashboards, and simulated Email/SMS notifications, and is designed to be easily extendable to a full backend-powered ERP system.
